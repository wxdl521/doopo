# 转绘工作台右侧面板加滚动

## 问题
右侧「项目文件 / 视频转绘工作台」栏是一个固定高度的纵向 flex 容器，里面依次是：设置面板（执行模式、画幅、目标市场、我的风格库调色台）、流程面板、项目文件树。只有最下面的文件树带滚动，上面两块没有滚动容器，内容一多就被挤出可视区域，鼠标滚轮也滑不动 —— 就是截图里看到的调色台被截断、无上下滑轨。

## 修复方案
把右侧栏改成「标题栏固定 + 下方整体一个滚动区」：

- `RestyleStudio.tsx` 右侧 `<aside>`：标题栏保持固定，其余内容（设置面板 + 流程面板 + 文件树）包进一个 `min-h-0 flex-1 overflow-y-auto` 的容器，让整栏可以上下滚动。
- `RestyleSetupPanel` 根节点补 `shrink-0`，避免在 flex 列中被压缩。
- `RestyleProcessPanel` 内部原有的 `max-h-[52vh] overflow-y-auto` 改为不限制高度（交给外层统一滚动），避免出现嵌套双滚动条互相打架。
- 文件树区域从自身滚动改为随外层滚动，保持内容完整展示。
- 给滚动容器加上项目已有的细滚动条样式（若无则用默认），并保证窄屏/移动端布局不受影响。

## 技术说明
仅改动 `src/components/restyle/RestyleStudio.tsx`、`RestyleSetupPanel.tsx`、`RestyleProcessPanel.tsx` 三个文件的布局类名，不涉及任何业务逻辑、数据与接口。
