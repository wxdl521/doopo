## 视频生成参考图模式重构（toapis 首帧+参考图混用报错修复）

- **根因**: toapis 三个模式互斥（首帧/首尾帧/多模态参考），前端 `generateVideoForGroup` 把第1张分镜当 `first_frame`、第2~N张当 `reference_image`，分镜≥2时必然混用报错
- **后端改动** (`src/lib/videoGenerate.functions.ts`):
  1. `DashScopeMediaItem` 加 `'last_frame'` 类型
  2. `ArkReferences` 加 `lastFrameImageUrl`，`buildArkContent` 加 last_frame→reference_image 映射
  3. `GenerateVideoInput` schema 加 `lastFrameImageUrl` 字段
  4. `generateVideo` handler 把 `lastFrameImageUrl` 转 `{type:'last_frame'}` media
  5. `toapisSubmit` 守卫改为"有 reference_image 时跳过 frame"（之前是"有 first_frame 时跳过 reference_image"，反过来了）
  6. kuaizi/ARK submit 路径同步处理 last_frame
- **前端改动** (`src/routes/workspace.$workspaceId.tsx`):
  - `generateVideoForGroup`: 按分镜数量分三种模式
    - 1张 → 首帧模式 (imageUrl=shot[0])
    - 2张 → 首尾帧模式 (imageUrl=shot[0], lastFrameImageUrl=shot[1])
    - 3+张 → 多模态参考模式 (全部分镜图+人物+场景+道具→referenceImageUrls，上限9，丢弃优先级: 道具>场景>人物)
  - `generateVideoFromStoryboardForGroup`: 改为多模态参考模式
    - 故事板图+分镜图(如有)+人物+场景+道具 全部作为 reference_image
    - 优先级(保留): 故事板>分镜>人物>场景>道具(丢弃)，上限9
- **验证**: tsc 0 错误
