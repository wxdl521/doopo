## 新增筷子科技"丽帧"视频生成后端

接入筷子科技 AI 开放平台丽帧视频生成 API，作为视频生成的第 4 个后端 `kuaizi`。
底层是火山方舟 Seedance 中转，但通过筷子科技走，未来可用其链式超分 / 版权放行等增值能力（本次只接基础视频生成）。

### 改动文件
1. **`src/lib/videoGenerate.functions.ts`**：
   - `getVideoBackend()` 加 `kuaizi` 分支（前缀 `kuaizi-`）
   - 新增 `KUAIZI_MODELS` 常量、`KUAIZI_DEFAULT_BASE_URL` 等配置
   - 新增 `getKuaiziConfig()` / `kuaiziModelToMode()` / `toKuaiziResolution()` / `kuaiziStatusToProgress()` / `kuaiziSubmit()` / `kuaiziPoll()`
   - `submitVideoTask()` 和 `pollVideoTask()` 各加 kuaizi 分支
   - `VideoBackend` 类型加 `'kuaizi'`
   - `PollServerInput` zod 枚举加 `'kuaizi'`
2. **`src/components/NewProjectDialog.tsx`** — `videoModels` 加 3 个选项：`kuaizi-lizhen-pro/fast/mini`
3. **`.env`** — 加 `KUAIZI_BASE_URL="https://aiopenapi.kuaizi.cn"`

### 关键约定
- 鉴权 Header：`ApiKey: <key>`（不是 `Authorization: Bearer`，注意首字母大写）
- 模型 ID 格式：`kuaizi-lizhen-{mode}`，mode ∈ {pro, fast, mini}
- 创建任务：POST `/ai-open-platform-api/v1/lz/video/task/create`
- 查询任务：POST `/ai-open-platform-api/v1/lz/video/task/status`（注意是 POST 不是 GET）
- 响应有外层包装：`{code, message, data, trace_id}`，需先查 `code === 0`
- 余额不足返回 HTTP 429
- Cloudflare Secret 名称：`KUAIZI_API_KEY`
- 强烈建议不要在筷子后台开启 IP 白名单（Cloudflare Workers 出口 IP 不固定）

### 验证
- `tsc --noEmit` 类型检查通过
- ESLint 仅剩 prettier + `no-explicit-any` / `no-empty`（与现有 ark/jimeng/dashscope 实现风格一致）

接入 ToAPIs (toapis.com) 中转火山方舟 Seedance 2 系列视频生成。

### 改动文件
1. **`src/lib/videoGenerate.functions.ts`**：
   - `getVideoBackend()` 加 `toapis` 分支（前缀 `toapis-`）
   - 新增 `TOAPIS_MODELS` 常量、`TOAPIS_DEFAULT_BASE_URL` 等配置
   - 新增 `getToapisConfig()` / `toapisModelToUpstream()` / `toToapisResolution()` / `toapisStatusToProgress()` / `toapisSubmit()` / `toapisPoll()`
   - `submitVideoTask()` 和 `pollVideoTask()` 各加 toapis 分支
   - `VideoBackend` 类型加 `'toapis'`，`PollServerInput` zod 枚举加 `'toapis'`
2. **`src/components/NewProjectDialog.tsx`** — `videoModels` 加 3 个选项：`toapis-seedance-2/fast/mini`
3. **`.env`** — 加 `TOAPIS_BASE_URL="https://toapis.com"`
4. **`.env.local`** — 加 `TOAPIS_API_KEY=sk-...`（用户提供）

### 关键约定
- 鉴权 Header：`Authorization: Bearer <key>`（标准 OpenAI 兼容）
- 模型 ID 格式：`toapis-seedance-2` / `toapis-seedance-2-fast` / `toapis-seedance-2-mini`
- 上游 model 名：剥离 `toapis-` 前缀得到 `seedance-2` / `seedance-2-fast` / `seedance-2-mini`
- 创建任务：POST `/v1/videos/generations`
- 查询任务：GET `/v1/videos/generations/{task_id}`（注意是 GET，跟筷子科技的 POST 不同）
- 状态映射：`queued`→queued, `in_progress`→running, `completed`→succeeded, `failed`→failed
- 视频 URL 在 `result.data[0].url`（不是 `content.video_url` 也不是 `data.video_url`）
- 视频 URL 24 小时有效
- Cloudflare Secret 名称：`TOAPIS_API_KEY`
